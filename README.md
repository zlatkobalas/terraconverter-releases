# TerraConverter — Releases                                                                                                                                                                        
 
Download-only repository for **TerraConverter**, a coordinate-conversion tool between Croatian and global coordinate systems (WGS84, HDKS, MGI 1901, HTRS96/TM, UTM/UPS, MGRS, ECEF, Plus Code, Geohash).
This repository contains **no source code** — only compiled builds, published under [Releases](../../releases). The application is closed-source freeware for non-commercial use; see [`LICENSE.md`](LICENSE.md) (English, canonical) or [`LICENSE.hr.md`](LICENSE.hr.md) (Croatian).
  
## Downloads                                                                                                                                                                                          
- **Windows desktop — Installer** (`TerraConverter_Setup_vX.Y.Z.exe`) — recommended for most users. Guided setup, Start Menu shortcut, clean uninstall via Windows "Apps & features".
- **Windows desktop — Portable** (`.zip`) — no installation, no admin rights, no registry changes. Extract anywhere and run `TerraConverter.exe` directly; useful for USB drives or restricted machines.
- **Android** — `.apk` asset from the latest release. Requires enabling "Install from unknown sources" for your browser/file manager, since the app is not distributed through Google Play.
