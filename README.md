# TerraConverter — Releases (Android)

Download-only repository for the **TerraConverter Android app**, a coordinate-conversion tool between Croatian and global coordinate systems (WGS84, HDKS, MGI 1901, HTRS96/TM, UTM/UPS, MGRS, ECEF, Plus Code, Geohash).
This repository contains **no source code** — only compiled builds, published under [Releases](../../releases). The application is closed-source freeware for non-commercial use; see [`LICENSE.md`](LICENSE.md) (English, canonical) or [`LICENSE.hr.md`](LICENSE.hr.md) (Croatian).

Looking for the desktop GUI or the command-line version instead? See
[terraconverter-releases-desktop](https://github.com/zlatkobalas/terraconverter-releases-desktop)
or [terraconverter-releases-cli](https://github.com/zlatkobalas/terraconverter-releases-cli).

## Downloads

- **Android** — `.apk` asset from the latest release. Requires enabling "Install from unknown sources" for your browser/file manager, since the app is not distributed through Google Play.
