# TerraConverter — Izdanja (Android)

Repozitorij isključivo za preuzimanje **TerraConverter Android aplikacije**, alata za pretvorbu koordinata između hrvatskih i globalnih koordinatnih sustava (WGS84, HDKS, MGI 1901, HTRS96/TM, UTM/UPS, MGRS, ECEF, Plus Code, Geohash).
Ovaj repozitorij **ne sadrži izvorni kod** — samo gotove izgradnje, objavljene pod [Releases](../../releases). Aplikacija je zatvoreni freeware za nekomercijalnu upotrebu; vidi [`LICENSE.hr.md`](LICENSE.hr.md) (hrvatski prijevod) ili [`LICENSE.md`](LICENSE.md) (engleski, mjerodavan).

Tražiš desktop GUI ili naredbeno-rednu (CLI) verziju? Vidi
[terraconverter-releases-desktop](https://github.com/zlatkobalas/terraconverter-releases-desktop)
ili [terraconverter-releases-cli](https://github.com/zlatkobalas/terraconverter-releases-cli).

## Preuzimanja

- **Android** — `.apk` prilog iz najnovijeg izdanja. Potrebno je omogućiti "Instaliraj iz nepoznatih izvora" za preglednik/upravitelj datoteka, pošto se aplikacija ne distribuira preko Google Playa.
